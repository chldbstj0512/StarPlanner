# 스타가계부 - 키워드 매칭 기반 가계부 앱

**키워드 매칭 기반 자동 분류** 기능을 갖춘 간단한 개인 가계부 앱입니다.  
지출·수입 기록을 빠르게 입력하고, 카테고리는 앱이 자동으로 추천해줍니다.
현재 Apple Appstore에서 설치 가능! 
https://apps.apple.com/kr/app/%EC%8A%A4%ED%83%80%EA%B0%80%EA%B3%84%EB%B6%80/id6752794686 </br>

## 주요 기능
- 지출/수입 간단 입력
- 키워드 기반 자동 카테고리 분류
- 월별 내역 조회
- 기본 통계(카테고리별 지출 비중)
- 로컬 데이터 저장

## 기술 스택
- React Native (Expo)
- SQLite 로컬 저장소
- 규칙 기반 키워드 매칭 시스템
